# PD1 darbs

**Autors:** Gustavs

## Palaišana

Palaidiet programmu ar komandu:

```bash
python kods/sveiciens.py
```

Programma izdrukā autora vārdu un kursa nosaukumu divās rindās.

## Ergonomika

- Skaidrs un īss programmas kods.
- Faili ir sakārtoti atsevišķās mapēs.
- Piezīmju fails netiek publicēts krātuvē.

## Secinājums

Grūtākais solis bija pareizi sakārtot projekta struktūru un pārbaudīt `.gitignore` darbību.

## Commit ziņu noteikums

Turpmāk commit ziņās īsi un konkrēti aprakstīšu paveiktās izmaiņas, lietojot darbības vārdu.
